Layer 2 / analytics engineering

Transform data into a tested analytical product.

-- dbt: fct_customer_month.sql select account_id, segment, month, starting_mrr, ending_mrr, churned_mrr, expansion_mrr, (ending_mrr - churned_mrr + expansion_mrr) / nullif(starting_mrr, 0) as nrr from {{ ref('stg_billing_monthly') }} where is_test_account = false

Layer 4 / AI on top of governed analytics

AI should ask the semantic model, not invent a new one.

User asks
“Why did NRR drop in Enterprise last month?”

The assistant needs the metric definition, filters, time context, and permitted data—not a raw table dump.

GoodData-powered answer
“Enterprise NRR fell 6 pts, driven by 11 accounts with contraction. The largest impact came from EMEA.”

Answer → visualization → drill path → follow-up question.

Context

Metrics, datasets, business terms, permissions.

Reasoning

Ask, filter, compare, explain, follow up.

Action

Create a view, share an insight, trigger a workflow.

Boundary: AI accelerates exploration and explanation; the semantic model remains the governed source of analytical meaning.
GoodData AI Assistant / Agentic AI Assistant can be accessed through supported UI, API, and SDK paths; verify the specific feature and version for the target environment.
