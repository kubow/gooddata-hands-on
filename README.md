# GoodData hands-on

A self-contained browser presentation about the end-to-end GoodData data cycle:

\`source → transform → semantic model → CI/CD → BI personas → executive decision\`

Open [\`index.html\`](./index.html) in a browser. Use arrow keys, the space bar, or the on-screen controls to navigate.

The deck is framework-free and organized around the full pipeline: ingestion/database → transformation → GoodData analytics → AI → delivery surfaces → end users.
